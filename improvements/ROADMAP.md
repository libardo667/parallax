# Roadmap

## Current Authority

`PRODUCT_PLAN.md` is the durable product and engineering north star. This
roadmap is the execution anchor for selecting and sequencing tracked work under
`items/`.

## Completed Stabilization Foundation

1. Reconciled the documented command surface with the current repository layout
   and restored a green default validation path.
2. Defined a canonical CA-free run schema and finished active sample migration.
3. Retired Wolfram and cellular-automaton runtime behavior while preserving only
   bounded legacy import compatibility where necessary.
4. Added focused tests around import migration and pure domain transformations.

## Active Product Lane

Streamline the Explore and Lens journeys through recommended defaults and
progressive disclosure. Keep the shared pipeline intact while reducing the
number of decisions required before a first useful result.

2. Consistent narrative, convergence, fault-line, emergence, and evidence
   hierarchy across result surfaces.
3. Citation provenance, derivation labels, and explicit degraded/fallback state.
4. Canonical run-state boundaries and narrower, testable pipeline modules.
5. News discovery expansion with clearer perspective semantics.
6. Hosted deployment only after URL-fetch and request-handling hardening.

## Minor Improvement Queue

2. Help text, compact non-default summaries, and keyboard ergonomics.
3. Mobile-friendly outputs and a more visible theme toggle.
4. Export improvements and discipline-color consistency.
5. Balanced-mode term deduplication and stronger synthesis attribution.

## Working Rule

Do not start a new major when the default validation path is red. Prefer
stabilization and pruning work before adding another major parallel lane. Every
major should name the user friction removed, the authoritative path changed,
the provenance or failure state exposed, and the rollback boundary.
